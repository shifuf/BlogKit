# 评论 AI 审核与音乐平台选择：生产验收

验收日期：2026-11-21（Asia/Shanghai）。实现已部署，代码已推送 `main`。

## 交付内容

- 文章、动态的根评论及回复复用已有 AI 配置，先持久保存为待审，再由数据库任务队列审核。只有严格的 `{"approved":true}` 才公开；拒绝不公开，失败保留待审并有限重试。
- 游客使用服务器生成的 HttpOnly、Secure、SameSite=Lax 持久 cookie，数据库只保存摘要。首次请求有共享初始化和跨标签页 Web Locks 协调；登录用户按真实用户 ID 判断归属，不以昵称识别。
- 本人待审、拒绝和垃圾规则拦截的评论可刷新读取；其他游客不可读取。公开及未公开状态均有角标，未公开状态明确标注仅自己可见。
- 回复预览、分页、自动刷新和计数已协调；旧请求、过期任务和人工操作后的 AI 结果不能覆盖当前状态。
- 回复邮件在事务提交后尽力投递，模板、回退及重复调用使用相同评论幂等键。数据库回滚不提前发送邮件；沿用原有尽力投递语义，提交后进程立即中断仍可能漏发邮件。
- 音乐选择支持全部平台、QQ 音乐、网易云音乐、酷狗音乐；先选择来源，再合并、截取结果，切换平台清理过期搜索和试听。

清除浏览器 cookie 或更换设备会形成新游客身份。历史没有凭证的游客待审评论不能凭昵称安全认领，仍需管理员处理。

## 公网验收

- 四条受控普通评论分别覆盖文章根评论、文章回复、动态根评论和动态回复，均由真实 AI 自动通过，并由另一独立游客身份读取为公开、非本人内容。
- 文章与动态提交后，以新查询确认待审仍存在；人工拒绝和垃圾规则拦截内容在本人页面刷新后仍可见。同名游客的浏览器无法读取这些未公开内容，也不会误显示“我”。
- 待审和拒绝内容不增加公开计数；通过后的根评论和回复各计一次。删除验收记录后，文章及动态公开计数恢复到验收前值。
- 文章、动态角标在 390px 深色和 320px 浅色的真实浏览器计算配色符合预期，无横向溢出。
- 首页和文章页在 320/390/1280px、浅色/深色共六组检查通过：主题跟随、手机菜单、正文、页脚及运行时错误检查通过；后台 320px 登录页检查通过。
- 后台 320px 音乐弹窗可切换平台，QQ、网易云显示对应平台结果并解析为本站流地址；无效平台被拒绝。
- 公网音频 `bytes=0-1023` 与 `bytes=1048576-1049599` 均返回 206、准确 `Content-Range` 和 1024 字节，保留 private/no-store。
- Edge 音频元素暂停后跳到 122 秒，恢复播放并继续前进；非零 Range 请求返回 206。
