# 音乐服务更新

移除米兔全部运行代码、测试入口与样式。保留统一搜索、自动切源、同源封面/音频代理和 Range 转发。

沿用现有播放器和后端服务，新增 ChKSz QQ、网易云、酷狗适配；迟言 QQ、网易云继续使用。不同提供商的相同歌名和歌手合为一条，内部保留独立候选。采用歌曲 mid/id 定位 ChKSz 曲目，避免搜索序号漂移。

后台新增音乐配置页：迟言 QQ 密钥、迟言网易云密钥、ChKSz 统一密钥。密钥存入现有配置表前用 DownloadCipher 密封，读取仅返回配置状态占位，保留占位不覆盖，清空可停用。环境变量作为未保存配置时的初始值。密钥不进入代码仓库、日志或公开响应。

选择复用现有组件而非另建播放器，避免损失已验证的快进和歌词点击行为。新增独立 API 客户端集中处理缓存、串行调用和额度错误。搜索缓存五分钟，曲目解析缓存三分钟，Range 重用解析缓存。401/403 暂停该 Key，402 暂停至北京时间次日，429 按 Retry-After 暂停；不自动重试。失败消息脱敏后在后台显示，其他提供商不受影响。

交付范围包含测试页更新、后端回归验证、GitHub main 更新与现有服务器部署。无需兼容已移除的米兔资源。

审查补充：网易云搜索同时接收 `data` 数组和 `data.songs`。网络锁按提供商隔离，普通接口错误只暂停对应路径，鉴权、额度和限流错误才暂停统一 Key。Retry-After 支持秒数与 HTTP 日期。公开搜索和音频代理使用概括错误，后台保留脱敏后的上游诊断；音频拉流不额外查询歌词。
